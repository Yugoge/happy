- **Happy-web-dev rebuild not needed**: The frontend bundle was already rebuilt at 17:21 and deployed. Only happy-cli (backend CLI) needs a rebuild for blocker 1. Do not rebuild happy-web-dev again unless instructed.
- **Stop-hook triggering**: Triggering a live stop-hook feedback event requires an overnight session that runs a hook. If no hook fires during normal Playwright interaction, the QA agent may need to run a test session that intentionally triggers a stop hook, OR verify the absence-of-bubble by comparing before/after with a known-hook-firing scenario. If not easily triggerable, static verification (existing source + test evidence) is acceptable for live-verification but must be documented as "triggered via test, not Playwright browser."
- **CronList trigger**: CronList tool call can be triggered in a dev session by sending the message "Please list all scheduled cron jobs" to the Claude agent. The agent will call CronList and the inline card will render. This is a normal UI interaction per CLAUDE.md.
- **Wide table trigger**: Send "Please show me a markdown table with columns: Tool Name | File Path | Status | Description | Notes | Result" to generate a wide table.
- **Codex session required for §5.15**: A Codex session must be active in the dev environment. If none exists, QA must create one via the UI (not code). Codex sessions are listed alongside Claude Code sessions in the session list.
- **Worktree binary path**: The correct rebuild path is `packages/happy-cli` inside THIS worktree (`/dev/shm/dev-workspace/happy-dev/.claude/worktrees/overnight-20260424-bfbc5f54`). Do NOT build from `/root/happy` or `/root/happy-dev`. Per CLAUDE.md dev daemon section, after build, daemon should be started with the worktree dist path.
- **happy-daemon-dev binary**: CLAUDE.md states dev daemon binary is `/root/happy-dev/packages/happy-cli/dist/index.mjs`. However, changes are in THIS worktree — so build from THIS worktree and configure the dev daemon to use THIS worktree's dist output, or copy dist to `/root/happy-dev/packages/happy-cli/dist/`.
