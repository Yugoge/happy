# BA Specification: Fix Hidden Horizontal Scroll Indicators on Web

**Request ID**: dev-20260403-210447-7
**Created**: 2026-04-03T21:04:47Z

## Goal

Show horizontal scroll indicators on web platform for code blocks and tables in the markdown renderer, so users can discover scrollable content without guessing.

## Context

The MarkdownView component renders code blocks and tables inside horizontal ScrollViews. Both have scroll indicators hidden on web:
- Code blocks (line 187): `showsHorizontalScrollIndicator={false}` unconditionally hides the indicator on all platforms.
- Tables (line 308): `showsHorizontalScrollIndicator={Platform.OS !== 'web'}` uses inverted logic -- it shows on native but hides on web, which is the opposite of the desired behavior.

On native (iOS/Android), hiding scroll indicators is standard UX because touch scrolling provides natural momentum feedback. On web, users rely on visible scrollbars to discover horizontally scrollable content, especially with mouse/trackpad input.

## Requirements (MoSCoW)

### Must Have
- Show horizontal scroll indicator for code blocks on web platform
- Show horizontal scroll indicator for tables on web platform
- Keep scroll indicators hidden on native platforms (iOS/Android) to preserve current mobile UX

### Should Have
- Consistent pattern: both code blocks and tables should use the same platform-conditional logic

### Could Have
- CSS-based scrollbar styling for web (thin scrollbar, themed colors)

### Won't Have (Non-Goals)
- Vertical scroll indicator changes
- Native platform scroll behavior changes
- Custom scroll indicator component

## Edge Cases & Risks

- React Native Web maps `showsHorizontalScrollIndicator` to CSS `overflow` properties; verify RNW version handles this correctly
- Ensure the scroll indicator does not overlap content or the copy button in code blocks

## Acceptance Criteria

### AC1: Code block scroll indicator visible on web
- GIVEN a markdown message containing a code block wider than the viewport
- WHEN the message is rendered on web platform
- THEN a horizontal scroll indicator (scrollbar) is visible on the code block

### AC2: Table scroll indicator visible on web
- GIVEN a markdown message containing a table wider than the viewport
- WHEN the message is rendered on web platform
- THEN a horizontal scroll indicator (scrollbar) is visible on the table

### AC3: Native platforms unaffected
- GIVEN a markdown message with wide code blocks or tables
- WHEN the message is rendered on iOS or Android
- THEN horizontal scroll indicators remain hidden (no visual change from current behavior)

## Technical Hints

- Affected file: `packages/happy-app/sources/components/markdown/MarkdownView.tsx`
- Line 187: Change `showsHorizontalScrollIndicator={false}` to `showsHorizontalScrollIndicator={Platform.OS === 'web'}`
- Line 308: Change `showsHorizontalScrollIndicator={Platform.OS !== 'web'}` to `showsHorizontalScrollIndicator={Platform.OS === 'web'}`
- Import: `Platform` is already imported from `react-native` in this file
- Pattern: `Platform.OS === 'web'` shows indicator on web, hides on native
