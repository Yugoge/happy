# BA Specification: Send Button Voice Mode on Web -- Disable Mic Trigger

**Request ID**: dev-20260403-210447-10
**Created**: 2026-04-03T21:04:47Z

## Goal

Prevent the send button from triggering browser microphone permission dialogs when input is empty on web platform, since voice input UX is poor on web browsers and the behavior is unexpected.

## Context

AgentInput.tsx renders a combined send/voice button. When the text input is empty and `onMicPress` is provided, pressing the button calls `props.onMicPress()` which triggers `requestMicrophonePermission()` from `microphonePermissions.ts`. On web, this immediately shows the browser's microphone permission dialog via `navigator.mediaDevices.getUserMedia()`, which is unexpected and intrusive. The button icon changes to a microphone image when in voice mode, but the visual distinction is subtle -- the button shape and color remain similar.

## Requirements (MoSCoW)

### Must Have
- On web platform (Platform.OS === 'web'), do not trigger microphone permission when send button is pressed with empty input
- The send button should show the arrow-up icon (disabled state) when input is empty on web, not the microphone icon

### Should Have
- On native platforms (iOS/Android), maintain existing voice mode behavior unchanged

### Could Have
- Add a dedicated voice button separate from send in a future iteration (not this fix)

### Won't Have (Non-Goals)
- Full voice input implementation for web
- Changing the voice recording UI on native platforms
- Adding a tooltip or explainer for voice mode

## Edge Cases & Risks

- Components that pass `onMicPress` to AgentInput may need awareness that it is ignored on web
- If web voice support improves in the future, this guard can be revisited
- Callers that rely on `onMicPress` being called on web will see changed behavior

## Acceptance Criteria

### AC1: No mic permission dialog on web
- GIVEN the user is on web platform with empty input field
- WHEN the send button is pressed
- THEN no microphone permission dialog appears

### AC2: Send button shows arrow icon on web with empty input
- GIVEN the user is on web platform with empty input field
- WHEN viewing the send button
- THEN the button shows the arrow-up icon (not microphone icon) and appears disabled

### AC3: Native voice mode preserved
- GIVEN the user is on iOS or Android with empty input field
- WHEN the send button is pressed
- THEN onMicPress is called as before (microphone icon visible)

## Technical Hints

- Affected file: `packages/happy-app/sources/components/AgentInput.tsx`
- Key logic at line 477-480: `handleSendPress` calls `props.onMicPress?.()` when `!hasText`
- Button icon logic at lines 1128-1136: shows microphone image when `props.onMicPress && !props.isMicActive`
- Fix: Gate both the `onMicPress?.()` call and the microphone icon rendering behind `Platform.OS !== 'web'`
- `canPressSendButton` at line 307-309 also references `props.onMicPress` -- needs web guard
- Related: `microphonePermissions.ts` already has web-specific code but the issue is that it gets called at all
