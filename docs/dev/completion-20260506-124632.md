## Root Cause Analysis

Happy already had an image preview component path when tool results contain `preview_uri`/data URI. The missing piece was the CLI mapper/result normalization for image-like tool completions: screenshot/imagegen outputs can arrive as markdown links or status text containing local image paths, and those were not converted into browser-loadable preview data.
