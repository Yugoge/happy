## Goal

Implement spec §5.3.D bullet 5 verbatim ("最佳形态：合并为一个 subagent lifecycle 卡，展示 agent nickname/id、started、completed、final summary"): merge the three subagent control verbs (`functions.spawn_agent` + `functions.wait_agent` + `functions.close_agent`) that currently render as three separate cards into a single lifecycle card. Preserve the cycle-2 fallback (3 stable cards) for old encrypted SessionMessage blobs that pre-date this cycle and therefore do NOT contain the new envelope.

Adopt the architect memo's Hybrid recommendation (option c): the CLI mapper emits a synthetic `functions.subagent_lifecycle` envelope keyed by `sessionSubagent` alongside the existing 3 control envelopes; the app renderer suppresses the 3 underlying cards when a lifecycle envelope exists for the same `sessionSubagent`. Default-not-suppress behavior means any bug surfaces as 4 cards (lifecycle + the 3 underlying), never as 0 cards.
