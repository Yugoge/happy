# BA Specification: Fix BashView Scrollbar + Bottom Border-Radius Conflict

**Request ID**: dev-20260408-170000
**Created**: 2026-04-08T17:00:00Z

## Goal

Resolve the conflict between horizontal scrollbar visibility and bottom border-radius in BashView, so the inline bash preview card has proper rounded bottom corners AND a functional horizontal scrollbar when content overflows.

## Context

BashView renders inline bash command output inside a ToolView card. The component hierarchy is:

```
ToolView.container (borderRadius: 8, overflow: 'hidden')
  └─ ToolView.content (paddingHorizontal: 12, paddingTop: 8, overflow: 'visible')
      └─ BashView.container (negative margins to fill edge-to-edge, borderBottomLeftRadius: 11, overflow: 'hidden')
          └─ ScrollView (horizontal)
              └─ CommandView.container (borderRadius: 8, overflow: 'hidden', padding: 16)
```

Two previous fix attempts both failed:
1. **Attempt 1** (commit 79c915b2): Removed `borderBottomLeftRadius/Right` and `overflow: 'hidden'` from BashView container, enabled `showsHorizontalScrollIndicator`. Result: scrollbar works but bottom corners are square/ugly.
2. **Attempt 2** (commit 7216dd70): Reverted to original state with border-radius + `overflow: 'hidden'` + scrollbar hidden. Result: corners look good but scrollbar is clipped/hidden.

The code was reverted to commit `a529bf91` which is the current HEAD state.

## Root Cause Analysis

The conflict stems from CSS/RN interaction between `overflow: 'hidden'` and `borderRadius`:

1. **`overflow: 'hidden'` on BashView.container** is required to make `borderBottomLeftRadius: 11` visually clip child content to the rounded corners. Without it, the ScrollView (a rectangular element) paints over the rounded corners.
2. **`overflow: 'hidden'` clips the scrollbar** because on React Native Web, the horizontal scrollbar renders in the overflow area below the ScrollView's content box. When the parent clips overflow, the scrollbar is hidden.
3. **ToolView.container already has `borderRadius: 8` and `overflow: 'hidden'`** -- this means the PARENT card already provides rounded corners and clipping. BashView's own `borderBottomLeftRadius: 11` is redundant for the outer shape since ToolView clips it. However, BashView uses 11px radius (not 8px) to account for the negative margins making BashView wider than ToolView's content area -- the inner radius needs to be `outerRadius - borderWidth` equivalent.

**Key insight**: Since BashView uses negative margins (`-12px` horizontal, `-9px` top, `-1px` bottom) to fill edge-to-edge inside the ToolView card, BashView's edges align with ToolView.container's edges. ToolView.container has `borderRadius: 8` and `overflow: 'hidden'`, which already clips the bottom corners of BashView. Therefore BashView does NOT need its own `overflow: 'hidden'` + `borderRadius` -- the parent ToolView handles it.

## Technical Hints

### Solution Approach

Remove `overflow: 'hidden'` and `borderBottomLeftRadius`/`borderBottomRightRadius` from BashView.container. The parent ToolView.container (`borderRadius: 8`, `overflow: 'hidden'`) already provides the rounded corner clipping for the card shape. BashView's negative margins push it to ToolView's edges, so ToolView's clip applies correctly.

Then set `showsHorizontalScrollIndicator={true}` (or just `showsHorizontalScrollIndicator` without `={false}`) on the ScrollView.

**Specific changes to `BashView.tsx`**:
1. Line 64: Change `showsHorizontalScrollIndicator={false}` to `showsHorizontalScrollIndicator={true}`
2. Lines 90-92: Remove `borderBottomLeftRadius: 11`, `borderBottomRightRadius: 11`, and `overflow: 'hidden'` from `styles.container`

**Why this works**: ToolView.container at line 327 has `borderRadius: 8` and `overflow: 'hidden'`. BashView.container uses negative margins to align with ToolView's edges. ToolView's overflow clipping will round the bottom corners of the BashView content. Without BashView's own `overflow: 'hidden'`, the ScrollView's scrollbar is no longer clipped by BashView and renders within ToolView's visible area.

**Risk**: If BashView's content visually bleeds outside the rounded corners, it means the negative margins are not perfectly aligned. Verify with Playwright that the corners look correct.
