## Edge Cases & Risks

- **R-1**: `process.title` may not survive `node --no-warnings` preamble
  or arg-zero rewriting on certain Node builds. Mitigation: unit test
  asserts `process.title.startsWith('happy-codex:')`; if flaky on a Node
  version, downgrade to "best-effort, helper does not fail."
- **R-2**: cgroup read on non-Linux (macOS dev) returns ENOENT. Mitigation:
  catch and omit field — `cgroup` is optional.
- **R-3**: cgroup contents change after the entry is written (process moved
  by systemd reload). Mitigation: documented as snapshot-at-bind; re-read
  on future sweep is out of scope.
- **R-4**: M1' `lastSweepRemoved` resets to 0 on daemon restart. Mitigation:
  documented as per-daemon-process counter; durable counters would require
  state-file mutation, out of scope.
- **R-5**: `/list` schema additivity from prior cycle AC6 must remain green.
  Mitigation: add a v1-consumer test asserting `mappingStats` is silently
  ignored by a v1-only schema reader.

  process state. Mitigation: tests reset `process.title` in `afterEach`,
