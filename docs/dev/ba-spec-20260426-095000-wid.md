### AC-WID5: posttool-subagent-track.py records subagent_calls on non-overnight cycles

- **Root cause**: `/root/.claude/hooks/posttool-subagent-track.py` lines
  192-194 contain a silent passthrough block:
  ```
  contract = contract_runtime.load_contract(session_id, cycle_id)
  if contract is None:
      sys.exit(0)
  ```
  When no cycle-contract JSON file exists for the session (the standard
  case for `/dev` and `/redev` invocations — only `/dev-overnight`
  produces this contract), the hook exits with status 0 without writing
  anything to the workflow bookmark's `subagent_calls` map. However
  `pretool-todo-validate.py` line 238 reads that exact map to authorize
  the `in_progress` → `completed` transition for any canonical step
  whose schema declares a `subagent_call` entry. Result: the validator
  demands the entry but the writer never produces it — every `/dev` and
  `/redev` cycle deadlocks at Step 3 (BA), Step 5a (QA), Step 6 (Dev),
  Step 8 (QA).
- **Evidence (this cycle)**: this `/redev5` session was unable to
  advance Step 3 → completed after a successful BA delegation,
  requiring the user to manually patch the workflow bookmark file at
  `/root/.claude/workflow-<session-id>.json` to set
  `subagent_calls["2"] = true`. The bookmark patch is reproducible —
  the same lockup will recur at Step 5a, Step 6, and Step 8 without
  further patches or a hook fix.
- **Fix direction (per user instruction)**: change the silent
  `sys.exit(0)` at posttool-subagent-track.py lines 193-194 to
  fall-through to a legacy path that writes the `subagent_calls` map
  key (string-form of the canonical step's index) to `true` whenever
  the canonical step has a `subagent_call` schema entry. The
  contract-driven artifact validation may remain for `/dev-overnight`
  cycles, but its absence MUST NOT block bookkeeping for `/dev` or
  `/redev` cycles. Concrete shape: when contract is None, locate the
  in-progress canonical step's index, set
  `state.subagent_calls[str(index)] = true` on the bookmark state,
  write the bookmark, exit zero. Do not perform schema validation in
  this fall-through path — just record the call.
- **Acceptance test (concrete, falsifiable)**:
  - GIVEN a `/dev` or `/redev` invocation (no overnight contract present)
  - WHEN a canonical step with `subagent_call` is reached and the
    corresponding Agent tool call completes successfully
  - THEN the workflow bookmark file's `subagent_calls` map key
    (string-form of the step index) MUST equal `true` after the Agent
    posttool fires.
  - AND the next TodoWrite that marks that step `completed` MUST pass
    `pretool-todo-validate.py` without orchestrator-side bookmark
    patching.
